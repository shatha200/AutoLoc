

# AutoLoc 

AutoLoc est une plateforme de **gestion de location de véhicules multi-agences** développée avec Java et Spring Boot.

## Technologies

* Java 17
* Spring Boot
* Spring Data JPA
* Maven
* MySQL
* Git / GitHub

##  Acteurs

* Client
* Agent d’agence
* Responsable d’agence
* Administrateur

##  Installation

```bash
git clone <repository-url>
cd AutoLoc
mvn clean install
mvn spring-boot:run
```

##  Base de données

```sql
CREATE DATABASE autoloc_db CHARACTER SET utf8mb4;
```

##  Objectif

Gérer les **clients, véhicules, agences et locations** à travers une application centralisée.
